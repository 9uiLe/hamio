# ターミナルプレビュー

端末プレビューは、疑似端末で実行した出力を、固定したフォントと端末サイズで画像化したものです。代表状態を PR とチャットで共有し、日本語、余白、色、カーソル更新を確認します。生成と掲載の操作は[開発手順](../development.md#8-ターミナル-ui-のプレビュー)を参照してください。

## 録画基盤の検証シナリオ

`fixture` は、録画基盤を確認するためのプログラムです。80列・20行の疑似端末で入力を待ち、Enter に応答して進捗と結果を出力します。hamio の製品 UI や公開 API は実装せず、外部接続や業務処理も行いません。

実行コマンドと撮影位置は [scenarios.ts](../../scripts/preview/scenarios.ts)、表示内容は [fixture.ts](../../scripts/preview/fixture.ts) に定義します。

## 確認できる範囲

画像は固定した端末エミュレーターによる再描画です。各 OS の実際の端末、画面読み上げ、製品の性能を保証するものではありません。操作途中は `./scripts/preview.sh --recording` で生成する `dist/preview/fixture.gif` で確認します。

画像と生成元の SHA-256、生成環境は [manifest.json](manifest.json) に記録します。hash の一致で更新漏れを検出し、表示の正しさは画像を開いて確認します。
