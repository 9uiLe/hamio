# 製品版 0.1.0 のリリース評価

本書は2026-09-17に行った配布候補の評価記録である。対象は macOS 15 arm64、Ubuntu 24.04 x64 / arm64。候補の再現性、実行時の動作、署名付き証明、同梱部品、性能の測定範囲を記録する。

評価時点では公開リリースはない。候補の検証は3対象で成功しているが、公開済み資産を使った導入は未検証である。公開手順と承認条件は[配布手順](distribution.md#保守者のリリース工程)、製品の品質目標は[基本設計](design.md)、脆弱性への対応は[セキュリティ方針](../SECURITY.md)に定める。

| ------------------ | ---------: | ---------------------- | --------------- | ------------------------ |
| macOS 15 arm64     |          5 | 成功                   | 成功            | 成功                     |
| Ubuntu 24.04 x64   |          4 | 成功                   | 成功            | 成功                     |
| Ubuntu 24.04 arm64 |          4 | 成功                   | 成功            | 成功                     |

macOS の5資産には全対象共通の `install.sh` を含む。独立プロジェクトの試験は、新しいローカル Git ディレクトリで、開発ランタイムのない PATH と限定した環境変数を使い、版、機能照会、非対話フォームを検査したものである。別の GitHub リポジトリへの公開操作は含まない。

provenance の検証では repository、workflow、source ref、commit、GitHub-hosted runner を照合した。インストーラーの単体試験に使う GitHub CLI の代替実装とは異なる検証経路である。Quality workflow の全体検査も同じ commit で成功した。

| 項目     | 対応範囲と検証上の限界                                                                                                  |

## 性能の実測範囲

性能値は[測定条件と生データ](research/reproducibility-performance.md)に基づく。測定機は M1 Pro、OS cache を温めた条件で各30試行。Release workflow の3対象の動作試験と、この性能測定は別の評価である。

| 指標           | 実測値                                             | 測定範囲                                                                 |
| -------------- | -------------------------------------------------- | ------------------------------------------------------------------------ |
| 小さい呼び出し | 機能照会 p95 21.94 ms、非対話フォーム p95 21.22 ms | 新規プロセスの起動から応答取得まで。cold start は未測定                  |
| 入力応答       | p95 2.028 ms                                       | PTY の入力送信から成功 JSON まで。実画面の描画や IME の遅延を含まない    |
| メモリ         | peak RSS 中央値30.16 MiB                           | 2,000進捗。定常 RSS、長時間反復、PSS、footprint は未測定                 |
| 並列実行       | p95 53.65 ms                                       | 4プロセス×20,000進捗の全終了まで。利用側の業務の並列性能は測定していない |

Linux の製品性能、30秒待機 CPU、実業務に対する追加時間、長時間のメモリ、実端末の描画遅延は未測定である。初期版ではこれらに数値保証を設けない。実測した指標も、すべての対応環境を代表するものではない。[性能予算](design.md#性能予算)の達成判定には、各目標に定めた条件での測定が必要となる。

同梱ランタイムは Bun 1.4.2、revision `744846f844374847c902b5e7fd59b4342a51ef99`。確認先、固定ソース、照会結果、許諾・再リンクの参照先は [Bun・native 依存の確認記録](research/runtime-review.md)とその生データに保存する。

| 確認              | 結果と範囲                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| npm 依存          | `bun audit` が46パッケージを検査し、既知の脆弱性を検出しなかった                                    |
| Bun の公開情報    | 確認時点で公開 advisory は0件。1.4.2 の修正内容を確認した                                           |
| native 依存       | 固定ソースの21 commit と Brotli 1.1.0 を OSV で照合し、22照会すべて該当項目は0件                    |
| 配布する notices  | 固定した上流の `LICENSE.md` と保存済みの通知が byte 一致。配布工程でも hash を検証する              |
| SBOM と許諾の範囲 | Bun 内部は集約した一部品。native 全部品の許諾本文の完全な集約や、上流 WebKit 全体の再ビルドは未検証 |

advisory や照会結果が0件であることは、安全性の証明ではない。OSV の収録範囲、fork、vendor 部品、OS 提供ライブラリ、polyfill、未公表の問題は照合だけで判定できない。署名付き SBOM も在庫の網羅性を保証しない。

## 公開時の判断

公開者は版タグの commit に対する3対象の候補検証、同梱部品の advisory・許諾、対応環境、性能の実測範囲を確認して `release` Environment を承認する。本書は判断の根拠資料であり、公開承認や全性能目標の達成を示すものではない。

公開後の導入試験では、immutable release と資産の結び付き、実際のインストーラー、利用側 Action を3対象で確認する。この試験は公開前の候補では完了できない。失敗した場合はその版の推奨を止め、影響と回避策を示し、公開済み資産を差し替えず新しい製品版で修正する。
