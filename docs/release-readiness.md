# リリース評価

製品版 `0.1.0` の候補を、macOS 15 arm64、Ubuntu 24.04 x64 / arm64 で評価する。公開可否は対象 commit の Release workflow、同梱部品の確認、保証範囲を合わせて判断する。公開操作は[配布手順](distribution.md#保守者のリリース工程)、報告と修正は[セキュリティ方針](../SECURITY.md)に従う。

## 検証記録

2026-09-17時点で公開リリースはない。以下は候補の評価であり、公開済み資産の導入成功を示すものではない。

| 対象         | 検証と記録                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Linux x64    | [Quality](https://github.com/9uiLe/hamio/actions/runs/35221548849): `ba21f81c4440e50adda7a7d3a1339b0e0e9f9875`、56テスト成功 |
| macOS arm64  | [Quality](https://github.com/9uiLe/hamio/actions/runs/35221569137): 同じ commit、56テスト成功                                |
| 配布の候補   | Release workflow の `verify` で3対象を検証し、実行 URL・commit・資産 hash を記録する                                         |
| 公開物の導入 | 公開後にのみ検証可能。immutable release、資産との結び付き、インストーラー、利用側 Action を3対象で検査する                   |

`verify` は実際の GitHub provenance を検証する。インストーラーの単体試験に使う GitHub CLI の代替実装とは区別する。独立プロジェクトの試験は新しい Git ディレクトリであり、別の GitHub リポジトリに対する公開操作を必要としない。

## 初期版の対応範囲

| 項目     | 対応範囲                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------- |
| OS / CPU | macOS 15 arm64、Ubuntu 24.04 x64 / arm64（glibc）。古い OS、musl、Intel Mac、Windows は対象外         |
| API      | API v1 の form、render、stream、capabilities。業務処理は利用側が実行                                  |
| 導入     | GitHub CLI と明示的な版指定による検証付き導入。通常実行に Bun・Node.js・Nix は不要                    |
| 端末     | PTY と固定サイズの製品プレビューで検証。すべての端末、IME、画面読み上げへの適合は保証しない           |
| 再現性   | 同じ runner・固定入力を別ディレクトリで二回生成した資産の byte 一致。異なるホスト間の一致は保証しない |

## 性能の実測範囲

製品の性能目標は[基本設計](design.md#7-性能設計)に定める。目標と実測済みの保証を混同しない。次は[測定条件と生データ](research/reproducibility-performance.md)に対応する値であり、CI runner の性能やすべての対応 OS を代表しない。

| 指標           | 実測と限界                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 小さい呼び出し | M1 Pro、温まった OS cache、30試行。機能照会 p95 21.94 ms、非対話フォーム p95 21.22 ms。cold start 未測定 |
| 入力応答       | PTY の入力送信から成功 JSON まで p95 2.028 ms。実画面の描画や IME の遅延ではない                         |
| メモリ         | 同条件の2,000進捗で peak RSS 中央値30.16 MiB。定常 RSS、長時間反復、PSS、footprint の保証ではない        |
| 並列実行       | 4プロセス×20,000進捗で全終了まで p95 53.65 ms。利用側の業務の並列性能を保証しない                        |
| サイズ         | macOS arm64 の実行ファイル62,259,954 bytes、gzip 25,556,809 bytes                                        |
| 未測定         | Linux の製品性能、30秒待機 CPU、実業務に対する追加時間、長時間のメモリ、実端末の描画遅延                 |

初期版では上記の未測定指標に数値保証を設けない。性能に影響する変更では対象の条件を測り、改善と悪化の両方を記録する。PR の通常検査へ定期 benchmark を追加しない。

## 同梱部品と保守

[Bun・native 依存の確認記録](research/runtime-review.md)に固定ソース、advisory、OSV 照会、許諾・再リンクの参照先を残す。npm の監査と native 部品の確認を区別する。GitHub 側では非公開報告、Dependabot alerts・security updates、secret scanning・push protection を有効にし、更新 PR は必須検査と所有者の判断を経てマージする。

## 公開時の判断

所有者は版タグの commit、全対象の検証成功、同梱 Bun の advisory・許諾記録、対応環境と未測定範囲を確認して Environment を承認する。証明の成功を、コードの無害性、完全な native SBOM、全性能目標の達成とみなさない。

公開後の導入試験が失敗した場合は、その版の推奨を止めて影響と回避策を公開し、資産を差し替えず新しい製品版で修正する。
