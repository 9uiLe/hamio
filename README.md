# hamio

hamio は、開発用スクリプトの入力フォーム、進捗、表、結果を統一するターミナル UI ツールです。実際の処理は利用側プロジェクトが担当し、Shell、Python、Go、TypeScript などから CLI と JSON で UI を利用します。

人には操作しやすいフォームと表示を、AI エージェントや CI には必要な情報に絞った構造化出力を提供します。業務処理の並列数や実行順序は利用側に残し、hamio の起動時間、メモリ、CPU、出力量をリリース条件として評価します。

本体は Bun + TypeScript で開発し、macOS と Linux 向けにランタイムを同梱して配布する設計です。開発環境は Nix で管理します。配布物の利用に Bun・Nix の事前導入は要求しません。

**開発状況: 設計段階。実装、動作検証、性能測定は未実施で、配布物は提供していません。**
